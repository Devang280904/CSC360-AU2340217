Working through this code helped me understand how custom 2D graphics and windows work in Java Swing. I learned that creating custom graphics involves extending JPanel and overriding paintComponent, while always calling super.paintComponent(g) first to clear the background and avoid visual glitches. By casting the default graphics context to Graphics2D, I could access more advanced drawing features. I also learned that drawing in Java is similar to using a physical paintbrush—you need to set properties such as Color.RED before drawing shapes like rectangles. Java’s coordinate system also starts at (0,0) in the top-left corner, with larger Y values moving objects downward. Finally, I learned how to place the custom canvas inside a JFrame and use setDefaultCloseOperation(3) to fully terminate the Java process when the window is closed.
