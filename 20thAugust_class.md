## 1. JFrame
- JFrame is present in the javax.swing package.
- It is used to create a window in Java.
- We can display components and drawings inside this window.

## 2. Anonymous Class
- Anonymous class means creating a class without giving it a name.
- We can use it when we need some small functionality only at one place.
- It is useful because we don't have to make a separate class for it.
  
## 3. Using super
- super is used to access the parent class methods.
- super.paint() calls the paint() method of the parent class.
- We use it first so that the normal painting process is done.
- After that, we can add our own drawing like changing color or drawing shapes.


## 4. drawRect()
- drawRect() is used to draw a rectangle.
- It takes x, y, width and height as values.
- (x, y) tells where the rectangle will start.
- width tells how much it goes in the x-direction.
- height tells how much it goes in the y-direction.
- We can also understand a rectangle using its two opposite points.
